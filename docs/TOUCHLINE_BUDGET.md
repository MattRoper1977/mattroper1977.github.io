# Touchline Dynasty byte budget

Ruled under Order TDSKY-2 §T2 (2026-09-02), on the per-title precedent Order
SC1 §4.4 set for Emberwild the same day (docs/EMBERWILD_BUDGET.md). Numbers
here were measured, not chosen; re-derive them before changing the budget.

## Why a per-route row exists

The estate's working per-file ceiling for a single-file game is 409,600 B
raw (400 KiB, the `B1` shape). `touchline/index.html` was 412,596 B as the
EWTD-1 Lane T base (sha256 `37c0905c…`) and is 416,020 B once the generated
MBM-MAKER-SPLASH region is regenerated by the frozen writer on Site main. The
generated furniture is not stripped and the ceiling is not waived silently:
this file is the contract row that raises it for `/touchline/` only, with both
numbers stated. Every other title keeps the estate rule.

## The budget for `/touchline/`

Three parts, per title, asserted where a static check can assert them:

- raw bytes: at most 512,000 B (asserted by `tools/verify_touchline.mjs`, gate TG0h)
- wire bytes: at most 160,000 B gzipped at level 6, which is what GitHub
  Pages serves (asserted by `tools/verify_touchline.mjs`, gate TG0i)
- parse: not pinned in a gate; the route's own TG5 paired-fps measurement and
  the games census are where a parse regression would show.

## Where Touchline stood when ruled

Measured 2026-09-02 on the Lane T candidate (Site branch
`claude/touchline-launch-td2`):

- raw 416,020 B against the retired 409,600 B line (+6,420 B, of which the
  regenerated splash region accounts for +3,424 B over the base); headroom
  under the new line 95,980 B
- wire 122,504 B gzipped (29.4 % of raw); headroom 37,496 B

## Firing controls

`node tools/verify_touchline.mjs --selftest` mutates a throwaway copy:

- 100,000 B of repeated comment bytes reds TG0h (raw) while TG0i stays green
  (the padding compresses away)
- 80,000 B of hex-encoded pseudo-random bytes reds TG0i (wire) while TG0h stays green

Both are asserted CAUGHT by the self-test, so a budget gate that stops
discriminating is a red self-test rather than a silent pass.
