Litmus only tells you acid OR alkali. Universal indicator gives a colour for each pH 0–14, so you also know how strong.

🚨 Misconception Busters

The four myths we are killing today

Click "Bust it!" on each card. We'll address the misconception, strike it through, and replace with the truth.

"pH 0 means no acid at all"

✅ Truth: pH 0 is the MOST strongly acidic. Lower pH = MORE H⁺. The scale runs 0–3 strongly acidic, 4–6 weakly acidic, 7 neutral, 8–10 weakly alkaline, 11–14 strongly alkaline.

"Bases and alkalis are the same thing"

✅ Truth: A base neutralises acid. An alkali is a base that also dissolves in water and releases OH⁻. CuO is a base but NOT an alkali (insoluble).

"H⁺ ions come from alkalis"

✅ Truth: H⁺ from acids. OH⁻ from alkalis. They combine: H⁺ + OH⁻ → H₂O.

"Neutralisation drives pH down to 0"

✅ Truth: Neutralisation moves pH towards 7, not 0. Acid + alkali cancel → neutral.

In the exam, if you're unsure, write the ion. Examiners often accept "H⁺ ions react with OH⁻ ions to form water" as the explanation behind any neutralisation question.

MCQ

1. Ionic equation for neutralisation:

The SHORT version shows only the ions that actually REACT.
H⁺ + OH⁻ → H₂OHCl + NaOH → NaCl + H₂O
Short

2. Difference between a base and an alkali.

Dissolves in water → alkali. Doesn't dissolve → just a base.

Base = neutralises acid. Alkali = soluble base, dissolves releasing OH⁻.

Short

3. Is CuO a base or an alkali? Explain.

CuO is a metal oxide. It's INSOLUBLE. What does that make it?

Base – it neutralises acid but is insoluble in water.

Long

4. NaOH added to HCl: describe pH, H⁺ concentration, temperature changes.

pH goes UP. H⁺ goes DOWN. Temperature goes UP (exothermic).

pH increases → 7. H⁺ decreases (used forming water). Temperature increases (exothermic).

⭐ Exam [4 marks]

5. Word equations: (a) HCl+NaOH [1]. (b) H₂SO₄+KOH [1]. (c) HCl+CuO [1]. (d) Which is NOT acid+alkali? [1]

CuO won't dissolve. So it neutralises acid but can't release OH⁻ in water.

(a) NaCl+H₂O. (b) K₂SO₄+H₂O. (c) CuCl₂+H₂O. (d) HCl+CuO — CuO is an insoluble base.

MCQ

1. pH 2 vs pH 5 — pH 2 has:

3 pH steps × 10 each = 10³ = 1000.
1000× more H⁺3× more H⁺
Short

2. Why is the ionic equation the SAME for ALL neutralisations?

Ions that don't take part = spectator ions. Only H⁺ and OH⁻ react.

Only H⁺ and OH⁻ react — the other ions are spectator ions.

Short

3. Salt from HNO₃ + Ca(OH)₂. Explain the pattern.

HNO₃ acid → nitrate ending. Ca(OH)₂ base → calcium. Ca(NO₃)₂.

Long

4. Why is CaO a base but Ca(OH)₂ both base AND alkali?

Insoluble = base only. Slightly soluble = also an alkali (releases OH⁻).

CaO neutralises acid (base) but is insoluble. Ca(OH)₂ dissolves slightly, releasing OH⁻ (so it's also an alkali).

⭐ Exam [6 marks]

5. MgO + H₂SO₄: (a) Balanced equation [2]. (b) Base or alkali? Justify [2]. (c) Ionic equation + spectator ions [2].

MgO is insoluble = base. Spectators: Mg²⁺ and SO₄²⁻ stay unchanged.

(a) MgO+H₂SO₄→MgSO₄+H₂O. (b) Base — insoluble. (c) H⁺+OH⁻→H₂O. Spectators: Mg²⁺, SO₄²⁻.
