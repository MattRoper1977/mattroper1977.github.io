Concept direction: Matthew Roper / Made by Matt

Game design and single-file implementation: Created from the supplied Ouroboros design bible as an original playable browser RPG.

Historical-fiction note: This is a stylised work of speculative fiction. Dialogue, events, technology and relationships are deliberately reimagined.

Technology: HTML5 Canvas, CSS, JavaScript and Web Audio. No external libraries, downloads, artwork, fonts or network connection are required.
