How to play

Goals decide the score. Turf decides how easily you can create them.

Player One

WS throttle & reverse
AD steer
Shift boost · Space pulse

Player Two

↑↓ throttle & reverse
←→ steer
/ boost · Enter pulse

Gamepad

Left stick steers and drives. Right trigger boosts. South button fires Pulse. Start pauses.

Touch

Use the floating analogue stick. Hold BOOST for speed. Tap PULSE to blast nearby cars and the core.

Turf

Own the floor

Your paint increases grip and boost recharge. Rival turf reduces both. Boosting paints a wider lane.

Pulse

Create space

A charged radial blast can shoot the core, block a rival or turn a goalmouth scramble.

Pickups

Break the pattern

Collect boost cells, magnets, shields and instant pulse resets. Each announces itself by colour.

Graphics

Automatic recovery

A readable Canvas fallback takes over if WebGL is unavailable or its context is lost; gameplay and controls continue.

Manual LAN Duel

One player hosts the authoritative match. Exchange the generated connection text directly with the other player on the same reachable local network. Pairing is fully manual. This build uses no signalling, STUN, TURN, relay, account or cloud service.

3 · Accept

The host pastes the join answer and completes the handshake.

Both current browsers must expose compatible local ICE candidates and be on the same reachable LAN. Some managed networks, browser privacy settings and file URLs block this.
