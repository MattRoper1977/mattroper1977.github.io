Evidence Binder — Moderator Pro v5

  1. Set up a binder. Add centre details, a unit, exact outcome wording and learners.
  2. Capture and safeguard. Photograph, paste or drop work; crop, pixelate faces, blackout identifiers, and draw arrows or circles before saving.
  3. Work hands-free. Browser voice dictation can fill assessor, witness and oral-response fields where Speech Recognition is supported. The app now identifies offline/network failures clearly; type manually whenever the browser speech service is unavailable.
  4. Run a carousel. Pin the practical context once, then save one separate EV record per learner while the register auto-advances.
  5. Moderate and close gaps. Choose a fixed, full-cohort or tiered square-root IQA sample, click matrix gaps to capture, print learner catch-up slips, and export the live matrix as an Excel-ready CSV.
  6. Protect the database. Drafts auto-recover after refresh; diagnostics safely remove orphan blobs; optional AES-GCM protects backup contents.
Safeguarding: all photos and records remain on this device. Use anonymised demonstration data and store backups according to your organisation’s data-protection procedures.
